This folder is a placeholder.

All pixel-art icons and the hero landscape currently ship as inline SVG
inside js/script.js (see ICONS and buildHeroScape()), so no files are
required here for the site to work.

Drop sprite sheets or illustration PNGs/SVGs here if you want to replace
any of the generated icons with hand-drawn artwork, then update the
matching renderIcon() call in js/script.js.
